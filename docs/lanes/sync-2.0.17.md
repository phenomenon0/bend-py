## The merge: where the two lines disagreed

Three files conflicted, as the plan mapped them: `bend2/base.bend` (3 hunks), `bend2/comp.ts`
(7 hunks), `gates/repo.ts` (2 hunks). The rule applied at every hunk: **ours stays where ours is a
decision we measured; upstream's is taken where it is strictly better or where we have no stake.**

Taken from upstream, whole: templates with `~` parameters and their laws; `term_higher`'s reduced
applications (`term_beta` gone); the bare-operator diagnostic; `emit_ctr`'s `at` layout and
`ctr_build` (`node_build` gone); `io_box` without `hot` (`io_seal` derives it from the cid);
`io_wait_on`'s deadline; the new effects (`File.read_at`, `File.size`, `File.write_bytes`,
`TCP.poll`, `IO.args`, `IO.random_u32`); `tools/bend-fmt-lsp`; the flake and the changelog; and
`f32_read`'s full-consume `strtof`.

Kept ours, each divergence named:

1. **C `io_str` keeps the adaptive-width decoder** (`str_alloc` / `str_fit`, 1 -> 2 -> 4 byte
   cells) and **JS `io_text` keeps the fatal-TextDecoder probe** over upstream's WHATWG incremental
   pair. The two disagree only on truncated input: ours emits one replacement per ill-formed byte,
   re-read as a lead; WHATWG emits one per maximal subpart. Ours is what `tests/strings` and
   `tests/regex` pin, on both hosts, and C/JS parity is the property we will not trade.
2. **`str_constant` / `str_static` keep their `String` early return** inside upstream's new
   `emit_ctr` tail, and the `adt.k !== "String"` stat guard rides with it, so a `String` `Ctr` that
   is not a closed literal chain still never goes static.
3. **The `string_*` native table stays ours**, and upstream's new `string_length` JS row is
   **dropped**: `tpl_ops` already emits that key for C and JS, and a second row would have taken the
   C implementation down with it. (Not a style call — it is a silent miscompile if merged as-is.)
4. **The f64 trio keeps `io_num`.** `f32_read` took upstream's `strtof`; `io_num` is now
   single-caller and is an R-lane target, not this merge's business.
5. **`Char.case_if` retires** with its last two callers: `Char.to_upper` / `to_lower` took
   upstream's branchless `Bool.to_u32` form.

## What the 2.0.16 bare-operator rule cost us

Upstream 2.0.16 makes a spaced binary operator (`a + b`) demand an enclosing `( .. : T)`. The sweep
reached `demos/python/`: every spaced operator now carries its `( .. : Nat)` — **except three sites
written as `Nat.add` / `Nat.mul` calls instead.** The reason is an upstream bug, worth reporting:

- `parse_term_ns` (`bend2/bend.ts:2204-2226`) prefixes any head `Ref` whose key starts with `.`.
  Under the suites' relative imports a local call's key is `../../demos/python/<mod>.<def>`, which
  starts with `.`, so the annotation produced `Nat../../demos/python/scanner.pos_col`.
- Upstream's own diagnostic at `bend2/bend.ts:726` spells the distinction correctly
  (`tm.k[0] === "." && tm.k[1] !== "."`). The namespace walk does not.

Also forced by upstream: `demos/python/nodes.bend`'s `+bare` is now `+many`. `+name` where `name`
resolves to a top-level def in the same file parses as a quantified datatype (`+D<..>`,
`bend2/bend.ts:1873`), not a binder.

`bend2/bend.ts` was not edited. It is human-written; both findings are reported, not patched.

## The lanes

**1. `lane-strgaps`** — the Python-gap `String` ops (`is_alpha` / `is_digit` / `is_alnum` /
`is_space` / `is_upper` / `is_lower` / `is_ascii` / `is_printable` / `is_identifier` / `is_title`,
`is_decimal` / `is_numeric` aliases, `remove_prefix` / `remove_suffix`, `center` on CPython's parity
rule, `swapcase`, `title`, `casefold`, `expandtabs`, `rsplit`, `rpartition`, `String.format` v1).
Pure `base.bend`, no natives; `gaps.bend` is generated by `gaps_gen.py` with CPython as the oracle
and `run.sh` re-checks the generator. Strings suite 97 -> 102.

**2. `lane-strings-demo`** — the strings tour's live page. `prelude.js` gives the emitted JS lane the
three things it asks node for (fs, `process.env`/`argv`, `bun:ffi`) as an in-memory file table, a
capturing `writeSync` and a `dlopen` stub, so `codepoints.bend` and `fuel.bend` run in a Worker with
no server round trip.

**3. `lane-strings-flagship`** — the tour's flagship frame. Line 3 of `gen_log.py`'s log is the line
that took Stack Overflow down on 2016-07-20 (their comment, 20,000 spaces, one `x`), met by their own
trim regex. `fuel.bend` doses it and prices every search; the same dose under a smaller tank is
refused at code point 0 with the price it needed. `selftest.sh` 11 -> 13 checks.

**4-5. `lane-base-fit-fold` and `lane-nits-base` — already landed; not merged.** See deviation 15.

**6. `lane-translator-t4`** — `ICall` and the module: N top-level defs of one source elaborated
together, the calls between them granted by a rank the kernel computes itself. Translator suite
28 -> 32.
